# 随工作台提供的手写字体

这两款字体直接取自 Google Fonts 仓库，未修改字体文件。均按 SIL Open Font License 1.1 分发，许可证随字体打包。

- [龙藏体（Long Cang）](https://github.com/google/fonts/tree/main/ofl/longcang)：`LongCang-Regular.ttf`，许可证 `LongCang-OFL.txt`。
